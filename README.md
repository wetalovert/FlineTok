# FlineTok

Офлайн-приложение для просмотра уже сохранённых видео из папок TikTok и MargyT в галерее Android.
Интерфейс в стиле Material You 3, океанская палитра, светлая, тёмная и системная темы.

## Возможности
- Запрос доступа к медиафайлам при первом запуске.
- Поиск видео только в папках TikTok и MargyT через MediaStore, остальные файлы не читаются.
- Вертикальная лента с листанием, случайным порядком и датой каждого видео.
- Пауза одним тапом, лайк двойным тапом (локально), избранное звездой.
- Прогресс-полоска с перемоткой перетаскиванием.
- Настройки: доступ, тема, вкладки «Лайки» и «Избранное». Из вкладок можно открыть любое видео.

## Сборка
1. Откройте папку проекта в Android Studio (Koala или новее).
2. Дождитесь синхронизации Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s) для отладочного билда,
   либо Build → Generate Signed Bundle / APK для релиза.

Требования: Android 8.0 (API 26) и выше, JDK 17.
